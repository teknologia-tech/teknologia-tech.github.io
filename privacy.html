Kebijakan Privasi POS KasirKu

Terakhir diperbarui: 27 November 2026

Teknologia Tech mengembangkan POS KasirKu (com.teknologiatech.kasirku). Kebijakan ini menjelaskan penggunaan data pada aplikasi dan website pendukungnya.

1. Data operasional toko

Aplikasi menyimpan data produk, foto, harga, stok, transaksi, laporan, profil toko, akun kasir lokal, PIN, serta informasi pelanggan seperti nama, nomor telepon, alamat dan kasbon apabila dimasukkan pengguna. Data digunakan untuk operasional toko dan disimpan dalam database serta penyimpanan lokal perangkat. Pengguna bertanggung jawab memiliki dasar yang sah untuk mencatat data pelanggan dan karyawan.

2. Izin dan fitur perangkat

Kamera digunakan untuk foto produk dan pemindaian barcode; pemilih foto dan file digunakan untuk gambar, impor dan restore. Bluetooth digunakan untuk menghubungkan printer. Internet diperlukan untuk layanan online seperti iklan, verifikasi pembelian, hadiah dan membuka tautan. Izin diberikan sesuai fitur dan dapat dikelola melalui pengaturan Android.

3. Ekspor dan pembagian data

Pengguna dapat mencetak atau membagikan nota, laporan, katalog HTML dan backup melalui aplikasi lain. File dapat berisi informasi toko atau pelanggan. Katalog yang dibagikan dapat berisi foto, harga, stok dan deskripsi produk. Penerima dapat menyimpan salinan. Layanan penerima seperti WhatsApp atau email tunduk pada kebijakan masing-masing. Teknologia Tech tidak mengendalikan salinan tersebut.

4. Iklan Google AdMob

Jika iklan diaktifkan, Google Mobile Ads SDK dapat mengumpulkan dan memproses alamat IP (termasuk perkiraan lokasi), pengenal perangkat atau iklan, interaksi aplikasi dan iklan, serta informasi diagnostik untuk penyajian iklan, pengukuran, analitik dan pencegahan penipuan. Google dan mitra iklan dapat memproses data sesuai pengaturan persetujuan dan hukum yang berlaku. Pilihan privasi iklan tersedia apabila diwajibkan dan didukung konfigurasi layanan. Lihat Kebijakan Privasi Google dan cara Google menggunakan informasi dari aplikasi mitra.

5. Pembelian Premium dan hadiah Semi-Pro

Jika layanan diaktifkan, Google Play menangani pembayaran. Aplikasi tidak meminta nomor kartu pembayaran. Token pembelian dapat dikirim melalui HTTPS ke layanan verifikasi untuk memeriksa hak Premium dan mencegah penyalahgunaan. Verifikasi hadiah iklan dapat menggunakan pengenal acak instalasi, informasi transaksi hadiah dan waktu pemberian hadiah untuk menentukan masa akses Semi-Pro. Data ini berbeda dari data operasional toko. Lihat kebijakan Google.

6. Penyimpanan dan keamanan

Data toko dipertahankan di perangkat selama pengguna menyimpannya. Backup terenkripsi menggunakan password yang dipilih pengguna; jangan bagikan password. Enkripsi backup tidak berarti seluruh database lokal terenkripsi. Lindungi perangkat, PIN dan file ekspor. Tidak ada metode keamanan yang menjamin perlindungan mutlak.

7. Retensi, penghapusan dan hak pengguna

Pengguna dapat menghapus data lokal melalui pengaturan Android dan menghapus salinan backup secara terpisah. Untuk data verifikasi online atau korespondensi bantuan, hubungi kami untuk meminta akses, koreksi atau penghapusan; data dapat dipertahankan sejauh diperlukan untuk kewajiban hukum, keamanan dan validasi transaksi. Detail retensi layanan verifikasi akan diperbarui sebelum layanan produksi diaktifkan. Lihat panduan penghapusan data.

8. Bantuan dan website

Jika menghubungi kami melalui email, kami menggunakan alamat email dan informasi yang Anda kirim untuk menjawab permintaan. Website statis ini tidak memasang formulir, pelacak analitik atau cookie sendiri. Penyedia hosting GitHub dapat memproses log akses dan alamat IP sesuai kebijakan privasi GitHub.

9. Audiens dan perubahan kebijakan

Aplikasi ditujukan untuk pengelola usaha dan bukan dirancang khusus bagi anak-anak. Kebijakan dapat diperbarui saat fitur atau praktik data berubah. Tanggal perubahan akan ditampilkan pada halaman ini.
