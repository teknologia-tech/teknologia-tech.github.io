Penghapusan Data

Perhatian: menghapus data aplikasi dapat menghilangkan seluruh transaksi, produk dan pengaturan secara permanen. Buat backup terlebih dahulu jika masih diperlukan.

Data lokal

  1. Buka Pengaturan Android → Aplikasi → POS KasirKu.
  2. Pilih Penyimpanan → Hapus data atau Hapus penyimpanan. Nama menu dapat berbeda.
  3. Hapus file backup, nota dan katalog yang tidak diperlukan dari penyimpanan dan layanan tempat Anda membagikannya.

Penghapusan aplikasi tidak otomatis menghapus file yang telah diekspor atau data pembelian Google Play.

Data layanan online

Untuk meminta penghapusan data bantuan atau verifikasi yang terkait dengan Anda, kirim email ke csteknologia@gmail.com. Jelaskan jenis data yang ingin dihapus. Jangan mengirim PIN, password backup atau token pembelian melalui email. Kami dapat meminta verifikasi yang proporsional dan menjelaskan data yang perlu dipertahankan karena kewajiban hukum atau keamanan.
